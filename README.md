# Language News Brief – a Claude skill

A daily news brief for learning (or relearning) a foreign language. Every morning Claude:

- finds fresh news from the country of your choice (hard news + pop culture),
- rewrites each story at your CEFR level, the way you'd explain it to a friend,
- adds 2–3 useful vocabulary terms and one grammar point per story,
- publishes everything to a colour-coded web page with read-aloud buttons,
- keeps a running vocabulary log so words and grammar topics don't repeat.

It started as a personal German "Morgenbrief" and works for any language.

## Install

1. Download this repository as a ZIP (green **Code** button → **Download ZIP**), or download just the `language-news-brief` folder.
2. In Claude, open **Settings → Capabilities → Skills** and upload the ZIP. (Menu names can differ slightly by plan and app version.)
3. Start a new chat and say something like: *"Set up a daily news brief for learning Spanish, news from Spain, B1."*

Claude asks a few questions, writes a sample story so you can check the level, then creates the page, the vocabulary log and the daily scheduled task.

## Requirements

Works in the Claude app with scheduled tasks, Docs and artifacts available. The read-aloud voice comes from your own device; "natural" or "enhanced" system voices sound best.
